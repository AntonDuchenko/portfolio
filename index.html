The Tale

About me

I like owning the whole path of a feature: working out the problem with designers and product managers, shaping the data model, writing the API and polishing the interface until it feels effortless. I care about speed you can measure — faster queries, lighter pages, fewer steps for the user — and about code the next person can pick up without a tour.

My first degree is in something else entirely: I trained as an electro-technical officer at the Kherson State Maritime Academy. I moved into software through Mate Academy in 2022–2023 and have been building products ever since.
